# Lately Kaohsiung · 最近高雄

A local phenomena guide for Kaohsiung — what’s blooming, fruiting, in season, or happening right now. Not a tourist map of sights, but a living notebook of place.

Homepage prototype.

## Run locally

```bash
python3 -m http.server 8765
```

Open [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

## Structure

- `index.html` — page markup
- `styles.css` — styles
- `app.js` — filters, search, sticky nav
- `images/` — card photos
- `mockups/` — design references for first-load and scrolled nav
